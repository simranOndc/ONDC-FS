    📖 Glossary ▼

    BAP Buyer App Platform

    Any borrower-facing application. Broadcasts loan applications to all lenders via the Gateway. Must comply with prevailing RBI digital lending guidelines.

    BPP Seller / Lender Platform

    RBI-registered Regulated Entities: Scheduled Commercial Banks (SCBs), NBFCs, Primary (Urban) Co-operative Banks (UCBs), Regional Rural Banks (RRBs). Acts as the catalog provider — publishes available loan products via on_search responses.

    Gateway BG

    ONDC network gateway that broadcasts search / discovery requests to all registered lenders simultaneously.

    Registry

    ONDC registry of all verified network participants (BAPs, BPPs, Gateways). Used for identity verification of each message sender/receiver.

    Catalog Provider

    The BPP (lender) that publishes its loan products, interest rates, EMI plans, and fee structures to the network. Each lender independently publishes their catalog in on_search responses to all connected BAPs.

    Provider

    The lender entity within an order — identified by provider.id (their ONDC registry ID). Contains descriptor, locations, and items (loan products).

    Item

    A specific loan product or EMI plan offered by a provider. Contains pricing, tags with loan terms (rate, tenure, amount range).

    Quote

    The itemised cost breakdown for a specific loan offer — includes principal, processing fee, insurance, GST, and net disbursed amount.

    Fulfillment

    Represents disbursement or repayment events. Each EMI installment is a separate fulfillment with its own start/end dates and amount.

    AA Account Aggregator

    RBI-licensed entities (e.g. Finvu, Onemoney) that enable borrowers to electronically share bank statements with lenders via a consent framework. Lenders create consent requests; borrower approves on the AA portal.

    Consent Handle

    A unique ID returned by the lender that identifies a specific consent request at the Account Aggregator.

    GSP GST Suvidha Provider

    GSTN-authorised providers. Buyer apps connect directly to retrieve GSTR-1, GSTR-2A, and GSTR-3B data for GST invoice financing use cases.

    SIDBI Dedupe Registry

    Registry mandatory for all lenders to check if an invoice has already been funded, and to update when a new loan is disbursed against it. Prevents double-funding of invoices.

    Credit Bureau / CIC

    RBI-regulated Credit Information Companies (e.g. CIBIL, Experian). Lenders pull borrower credit files to assess creditworthiness during underwriting.

    KYC Know Your Customer

    Identity verification required before loan disbursement. Individuals: Aadhar eKYC or DigiLocker pull. Sole proprietors: both individual KYC + entity KYC (Udyam certificate).

    eSign

    Electronic signing of the loan agreement using either Aadhar OTP-based eSign or clickwrap acceptance.

    eNACH / eMandate

    Electronic National Automated Clearing House mandate — authorises automatic EMI debits from the borrower's bank account each month.

    UIDAI / DigiLocker

    Government platforms for Aadhar-based eKYC and document retrieval (Udyam Certificate, Aadhar XML).

    Penny Drop

    A small test credit (₹1) to the borrower's bank account to verify the account details before disbursement.

    Personal Loan

    Unsecured loan for salaried or self-employed individuals. Underwritten using bureau data and optionally AA bank statements.

    GST Invoice Financing

    Unsecured loan for sole proprietors backed by their GST invoice data (GSTR-1, GSTR-2A, GSTR-3B). Lenders fund specific invoices.

    NTB New To Bank

    A borrower with no existing relationship with the lender. Requires full KYC and underwriting from scratch.

    ETB Existing To Bank

    A borrower with an existing relationship with the lender. May qualify for pre-approved offers without AA consent.

    STP Straight-Through Processing

    Fully automated loan application and disbursement with no manual intervention required.

    Buyer Finder Fee

    A fee the BAP shares with the lender through the protocol, dynamically adjustable. Lenders can filter offers based on whether they accept the specified fee.

    transaction_id

    A UUID that ties all API messages in a single end-to-end transaction (search → on_search → select → … → confirm). Same value across the entire journey.

    message_id

    Unique to each individual API call. The corresponding response (e.g. on_search for search) carries the same message_id.

    TTL Time To Live

    ISO 8601 duration (e.g. PT10M = 10 minutes) — how long the request remains valid. Receivers should reject stale messages.

    ACK / NACK

    Synchronous acknowledgement returned immediately. ACK = accepted for asynchronous processing. NACK = rejected, with error details.

    Tags

    Extensible key-value metadata groups attached to items, fulfillments, payments, or orders. Used to carry ONDC-specific fields like loan terms, consent info, and fees.

    Descriptor

    A structured label — contains a code (machine-readable) and optionally name, short_desc, long_desc, images.
